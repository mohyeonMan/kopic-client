# API 이벤트/뮤테이션 매트릭스

## 사용자 목적
- 어떤 사용자 행동이 어떤 이벤트를 보내고, 어떤 상태가 어떻게 바뀌는지 한눈에 확인한다.
- 이관 후 기능 누락을 이벤트 단위로 검증한다.

## 진입 위치
- 사용자 행동(입장, 설정 변경, 정답 제출, 그리기, 게임 시작, 단어 선택) 발생 시점.
- 웹소켓 수신 이벤트 처리 시점.

## 주요 동작 흐름
1. 사용자 행동이 로컬 액션으로 변환된다.
2. 로컬 액션은 필요한 경우 즉시 optimistic 반영을 수행한다.
3. 동시에 대응하는 웹소켓 이벤트를 전송한다.
4. 서버 이벤트 수신 시 정규화 후 리듀서가 최종 상태를 확정한다.

## 상태 변화
- 세션 전이:
  - `joinRequested` → `joinAccepted` 또는 `joinFailed`.
- 방 전이:
  - `LOBBY` → `RUNNING` → `RESULT` → `LOBBY`.
- 턴 전이:
  - `READY` → `WORD_CHOICE` → `DRAWING` → `TURN_END`.

## 사용 API
- 클라이언트 송신(legacy):
  - `107`: 게임 설정 변경
  - `200`: 게임 시작 요청
  - `201`: 그림 stroke/clear
  - `203`: 단어 선택
  - `204`: 정답 제출
- 서버 수신(legacy, 핵심):
  - 스냅샷/입장: `300`, `408`, `1999`
  - 참여자: `301`, `302`
  - 게임 흐름: `200`, `202`, `203`, `205`, `206`, `207`, `208`, `209`, `210`, `211`
  - 채팅/캔버스: `204`, `403`, `201`, `402`

## 성공 흐름
- 입장 성공: 스냅샷 적용 + 세션 승인 + 게임 화면 이동.
- 설정 변경: 로컬 반영 후 서버 동기화 유지.
- 정답 제출: 로컬 채팅 즉시 반영 후 서버 전송.
- 그리기: 청크 전송 + 로컬 커밋 + 서버 브로드캐스트 반영.

## 실패 흐름
- `1999` 수신 시 입장 실패로 되돌리고 방 상태 초기화.
- 연결 실패/세션 종료 시 연결 오류 전파 후 메인으로 복귀.
- 송신 실패 시 일부 동작은 로컬 optimistic 상태만 남을 수 있음.

## 로딩 처리
- 입장 로딩: `joinPending` 상태와 버튼 비활성화.
- 게임 흐름 로딩은 단계별 오버레이/카운트다운으로 대체.

## 빈 상태 처리
- 스냅샷 필드 누락 시 fallback 값으로 안전한 상태 유지.
- 채팅/참여자/캔버스는 빈 배열 fallback을 사용.

## 검증(Validation)
- 디코더에서 타입 검증 후 실패 payload 무시.
- 설정 변경 권한: 방장만 허용.
- 정답 제출 길이 제한: 50자.
- 단어 선택 인덱스는 음수/비정상 값 보정.

## 상황별 인터랙션/액션 디테일
- `300/408` 스냅샷 수신: 입장 성공 처리와 함께 화면이 `/game`으로 넘어가고, 참여자/보드/채팅 초기 뷰가 한 번에 채워진다.
- `301` 입장 이벤트: 참여자 카드가 엔터 애니메이션(`participant-card-enter`)로 유입되고, 시스템 알림 채팅이 추가되어 채팅 패널에도 변화가 생긴다.
- `302` 퇴장 이벤트: 참여자 목록에서 카드가 이그짓 애니메이션(`participant-card-exit`) 후 제거되고, 필요 시 방장 변경 알림이 채팅에 표시된다.
- `200/202/205/206` 게임 흐름 이벤트: 라운드/턴 단계가 갱신되며 풀스크린 오버레이가 `open/closed` 클래스로 전환된다.
- `203` 단어 선택 이벤트: 출제자에게 단어 선택 카드와 선택 버튼이 열리고, 비출제자에게는 대기 문구 카드가 같은 슬롯에서 표시된다.
- `204/403` 채팅 이벤트: 새 메시지 누적, 하단 고정 여부에 따른 자동 스크롤 또는 `최신 채팅 이동` 버튼 노출, tone별 색상 강조가 함께 적용된다.
- `201/402` 캔버스 이벤트: stroke는 즉시 보드에 누적되고 clear 이벤트는 보드를 즉시 비우며 관련 큐를 정리한다.
- `207/208/209/210` 점수/정답 이벤트: 정답자/출제자 행 강조, 참여자 카드 색상 변화, 턴 종료 점수 테이블 내용이 동기 갱신된다.
- `211` 결과 이벤트: 결과 스크린 셔터 애니메이션과 점멸 테두리가 나타나고, 순위 리스트에서 1등 강조 스타일이 적용된다.
- `1999` 입장 실패 이벤트: 게임 화면 대신 입장 실패 모달 경로로 복귀하며, join 상태가 초기화되어 재시도 가능한 화면 상태가 된다.

## 부수 효과(Side Effect)
- 캔버스 inbound 이벤트는 `requestAnimationFrame` 배치 처리.
- clear 이벤트는 큐 정리 후 상태 clear.
- 입퇴장/방장변경/정답자 메시지 알림 생성.

## 엣지 케이스
- 서버 키 스키마가 달라도 다중 키 디코딩으로 흡수.
- 스냅샷에 내 세션 식별자가 없을 때 닉네임 기반 추론.
- 턴 캔버스 누락 스냅샷에서 이전 stroke 보존.

## 관련 엔티티
- legacy:
  - `AppStateContext`, `appStateReducer`, `appStateWsAdapter`, `appStateSnapshot`
- 신규:
  - `useGameSessionRuntime`, `gameSessionApi`, `gameStore`, `roomSnapshotNormalizer`

## 현재 마이그레이션 상태
- 신규 src 존재 여부: 존재.
- behavior parity 충족 여부: 부분 충족.
- 아직 누락된 부분:
  - 특권 채팅 가시성, 시스템 알림 생성, 재연결 정책 등 일부 이벤트 후처리 누락 가능.
- migration 위험 요소:
  - 이벤트는 수신되지만 후처리 뮤테이션이 빠져 기능이 조용히 축소될 가능성.
