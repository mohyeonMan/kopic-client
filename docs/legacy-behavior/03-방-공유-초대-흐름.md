# 방 공유/초대 흐름

## 사용자 목적
- 현재 방에 다른 사용자를 초대하기 위해 링크, QR, 방코드를 공유한다.

## 진입 위치
- 게임 화면 상단 공유 버튼.
- 공유 메뉴: 링크 복사, QR 코드, 방 코드 복사, 네이티브 공유.

## 주요 동작 흐름
1. 공유 버튼 클릭 시 메뉴를 열고, 바깥 클릭 또는 `Esc`로 닫는다.
2. 링크 복사/방코드 복사 시 클립보드 API를 시도하고 실패 시 fallback을 사용한다.
3. QR 코드 메뉴 클릭 시 모달을 열고 동적 `qrcode` 로딩 후 이미지를 생성한다.
4. 네이티브 공유 지원 시 후보 payload를 순차 시도하고, 실패 시 링크 복사로 대체한다.
5. 모든 공유 동작 후 메뉴를 닫고 짧은 피드백 문구를 표시한다.

## 상태 변화
- `shareMenuOpen`, `qrModalOpen`
- `qrCodeDataUrl`, `qrCodeError`
- `shareFeedback` (일시 상태)

## 사용 API
- `navigator.clipboard.writeText`
- fallback: `document.execCommand('copy')`
- `navigator.share`, `navigator.canShare`
- `import('qrcode').toDataURL(...)`

## 성공 흐름
- 링크/코드 복사 성공 시 피드백 표시(`링크 복사됨`, `코드 복사됨`).
- 네이티브 공유 성공 시 `공유됨`.
- QR 생성 성공 시 모달 내 QR 이미지 표시.

## 실패 흐름
- 복사 실패 시 `복사 실패`.
- 네이티브 공유 실패 시 링크 복사 fallback 시도.
- 공유 취소(`AbortError`)는 실패 토스트 없이 피드백 초기화.
- QR 생성 실패 시 오류 상태로 전환.

## 로딩 처리
- legacy는 QR 생성 중 명시 문구를 표시하지 않고, 이미지가 준비되면 출력한다.
- 피드백 메시지는 약 1.4초 후 자동 소거된다.

## 빈 상태 처리
- 방코드가 비어 있으면 공유 버튼 자체를 노출하지 않는다.
- 초대 URL이 없으면 공유 동작 함수는 조기 반환한다.

## 검증(Validation)
- `roomCode.trim().length > 0`일 때만 공유 가능.
- 메뉴/모달 열림 상태에 따라 이벤트 리스너를 조건부 등록/해제.

## 상황별 인터랙션/액션 디테일
- 공유 버튼 토글 상태: 메뉴가 열리면 공유 버튼에 `topbar-share-button-open`이 붙어 inset 테두리 그림자가 생기고, 닫히면 원복된다.
- 공유 메뉴 열림 모션: `topbar-share-menu`는 기본 `opacity: 0`, `translateY(-6px)` 상태에서 `topbar-share-menu-open` 시 `opacity: 1`, `translateY(0)`으로 슬라이드-페이드 인 된다.
- 메뉴 외부 클릭/ESC 닫힘: 메뉴 오픈 중에는 전역 `pointerdown`, `keydown` 리스너가 붙어 바깥 클릭 또는 `Escape` 입력으로 즉시 닫힌다.
- 메뉴 아이템 hover 액션: 각 메뉴 항목은 hover 시 배경이 짙어지고 `translateY(-1px)`로 살짝 떠오른다.
- 공유 피드백 표시 방식: 성공/실패 문구(`링크 복사됨`, `복사 실패` 등)가 공유 버튼 텍스트를 일시 대체하고, 약 1.4초 후 자동 복귀한다.
- QR 모달 표시: 열림 시 블러 백드롭(`topbar-qr-modal-backdrop`) + 카드 모달이 뜨며, `body.style.overflow='hidden'`으로 배경 스크롤을 잠근다.
- QR 모달 닫힘 액션: 백드롭 클릭 또는 `Escape`로 닫힌다. 닫히면 body 스크롤 잠금이 즉시 해제된다.
- QR 생성 중 체감: 모달은 먼저 열리고 QR 이미지는 비동기 생성 완료 시 표시된다. 실패 시 이미지가 비고 오류 상태(`qrCodeError`)로 전환된다.
- 네이티브 공유 취소 처리: 사용자가 OS 공유 시트를 취소(`AbortError`)하면 실패 토스트 없이 피드백 문자열만 초기화된다.

## 부수 효과(Side Effect)
- body 스크롤 잠금(모달 오픈 시).
- 전역 `pointerdown`, `keydown` 리스너 등록/해제.
- QR 동적 import.

## 엣지 케이스
- 네이티브 공유가 부분 지원되는 기기에서 후보 payload를 순차적으로 다운그레이드.
- 클립보드 API 미지원 환경에서도 텍스트영역 fallback으로 복사 시도.

## 관련 엔티티
- 앱 셸 상단바 UI 상태
- 현재 `roomCode`
- 브라우저 공유/클립보드 기능

## 현재 마이그레이션 상태
- 신규 src 존재 여부: 존재 (`RoomInviteShareMenu`, `useRoomInviteShare`).
- behavior parity 충족 여부: 대부분 충족.
- 아직 누락된 부분:
  - legacy와 신규의 QR 실패 안내 방식이 다름(legacy는 실패 시 비어 보일 수 있음, 신규는 문구 표시).
- migration 위험 요소:
  - 플랫폼별 공유 API 예외 처리 분기 회귀 시 복사 fallback이 조용히 깨질 수 있음.
