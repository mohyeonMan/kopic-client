# 참여자 패널/말풍선 피드백

## 사용자 목적
- 현재 참가자 상태(점수/출제자/정답자/방장)를 즉시 파악한다.
- 최근 채팅이 누가 보낸 것인지 패널 옆 말풍선으로 빠르게 인지한다.

## 진입 위치
- 게임 페이지 좌측 참여자 패널.
- 모바일에서는 패널 전환 탭으로 참여자 패널 활성화.

## 주요 동작 흐름
1. 참가자 목록을 joinOrder 기준으로 표시한다.
2. 턴 상태에 따라 카드 톤(출제자/정답자/기본)을 다르게 렌더링한다.
3. 참가자 입퇴장 시 카드 엔터/이그짓 애니메이션을 적용한다.
4. 최근 채팅에서 발신자별 최신 메시지를 추출해 3초간 말풍선으로 표시한다.
5. 패널 스크롤/창 크기 변경 시 말풍선 좌표를 다시 계산한다.

## 상태 변화
- `animatedParticipants` (stable/enter/exit).
- `participantBubbles` 좌표/텍스트 목록.
- `chatSeenAtById` 메모리 맵(최근 메시지 시각 추적).

## 사용 API
- 직접 네트워크 호출 없음.
- 채팅/참여자 상태를 읽어 파생 상태 계산.

## 성공 흐름
- 플레이어는 패널만 봐도 현재 역할과 점수를 파악할 수 있다.
- 최근 발화가 말풍선으로 시각화되어 채팅 패널을 열지 않아도 대화 흐름을 따라갈 수 있다.

## 실패 흐름
- DOM ref를 확보하지 못하면 해당 참가자의 말풍선을 생략한다.

## 로딩 처리
- 별도 로딩 없음.

## 빈 상태 처리
- 참가자가 없으면 카드 목록은 비어 있으며(legacy), 신규 src는 안내 문구를 노출한다.
- 최근 채팅이 없으면 말풍선 레이어는 빈 상태.

## 검증(Validation)
- 말풍선 표시 조건:
  - 최근 8개 메시지 검사.
  - 메시지 생성 후 3초 이내만 노출.
  - 사라진 메시지는 60초 이후 seen 맵에서 정리.
- 텍스트 길이 20자 초과 시 말풍선 텍스트를 축약한다.

## 상황별 인터랙션/액션 디테일
- 기본 카드 톤: 참여자 카드는 기본적으로 옅은 배경 + 중성 테두리(`rgba(32, 50, 71, 0.18)`)를 사용한다.
- 내 카드 강조: 내 카드에는 `participant-card-self`가 추가되어 주황 계열 테두리(`rgba(225, 122, 46, 0.45)`)와 배경 tint가 적용된다.
- 출제자 카드 강조: `participant-card-drawer`는 더 진한 주황 테두리와 inset 라인을 써서 현재 출제자를 명확히 구분한다.
- 정답자 카드 강조: `participant-card-correct`는 녹색 계열 그라디언트 배경, 진한 녹색 테두리(`rgba(17, 104, 68, 0.82)`), 추가 inset/outer shadow로 즉시 구분된다.
- 입장 애니메이션: `participant-card-enter`에서 220ms 동안 `translateX(-16px) -> 0`, `opacity 0 -> 1` 슬라이드 인이 실행된다.
- 퇴장 애니메이션: `participant-card-exit`에서 180ms 동안 반대로 슬라이드 아웃하며 `pointer-events: none`으로 중간 클릭을 차단한다.
- 말풍선 등장 모션: 참가자 옆 말풍선은 3초 애니메이션으로 약간 왼쪽에서 나타나(`translateX(-4px)`) 머물다가 오른쪽으로 빠지며 사라진다(`translateX(6px)`).
- 말풍선 위치 추적: 참여자 패널 스크롤/윈도우 리사이즈마다 좌표를 재계산해 카드 오른쪽 14px 지점에 다시 붙인다.
- 모바일 표시 정책: `max-width: 980px`에서는 말풍선 레이어 자체를 숨겨(모바일 좁은 폭 충돌 방지), 패널 카드 정보만 유지한다.
- 모바일 참여자 패널 전환: `game-participant-panel-mobile-active`일 때만 패널이 보이고, 비활성 시 `game-side-panel-mobile-hidden`으로 DOM은 유지하되 화면에서 제거된다.
- 모바일 스크롤 체감: 활성 패널 내부(`side-panel-scroll-inner`)는 터치 스크롤과 thin 스크롤바를 제공해 긴 참여자 목록을 독립적으로 탐색한다.

## 부수 효과(Side Effect)
- `scroll`/`resize` 리스너 등록 후 좌표 재계산.
- 참여자 카드 DOM ref 맵 유지.

## 엣지 케이스
- 발신자의 `senderSessionId`를 찾지 못하면 말풍선 생성 대상에서 제외된다.
- 빠른 입퇴장 반복 시 카드 애니메이션 상태가 겹칠 수 있어 phase 관리가 필요하다.

## 관련 엔티티
- `room.participants`
- `room.currentTurn.correctSessionIds`, `drawerSessionId`
- `room.chat[].senderSessionId`, `createdAt`

## 현재 마이그레이션 상태
- 신규 src 존재 여부: 부분 존재 (`ParticipantScorePanel`은 존재, 말풍선 계층 없음).
- behavior parity 충족 여부: 미충족.
- 아직 누락된 부분:
  - 참여자 말풍선 피드백 레이어 미이관.
  - 참여자 카드 엔터/이그짓 애니메이션 미이관.
- migration 위험 요소:
  - 실시간 상호작용 감각이 약해져 채팅/참여자 맥락 파악 속도가 떨어질 위험.
