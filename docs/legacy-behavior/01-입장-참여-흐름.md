# 입장/참여 흐름

## 사용자 목적
- 사용자가 닉네임을 입력하고 게임 방에 입장한다.
- 빠른입장, 방만들기, 방코드 직접 참여 중 원하는 방식으로 진입한다.

## 진입 위치
- 메인 경로(`/`) 진입 시 입장 화면.
- 초대 링크 경로(`/{roomCode}`) 또는 쿼리(`?roomCode=`) 진입 시 방참여 모달 자동 오픈.

## 주요 동작 흐름
1. 사용자가 닉네임을 입력한다.
2. 빠른입장/방만들기 버튼은 닉네임 유효 시 활성화된다.
3. 방참여 버튼 클릭 또는 초대 링크 진입 시 방참여 모달이 열린다.
4. 모달에서 닉네임+방코드 유효성 검사를 통과하면 참여 요청을 보낸다.
5. 세션이 `joinAccepted` 상태가 되면 `/game`으로 이동한다.
6. 실패 시 입장 실패 모달 또는 연결 실패 모달을 표시한다.

## 상태 변화
- 닉네임 입력 시 `session.nickname` 즉시 갱신.
- 참여 요청 시 `joinPending=true`, `joinAccepted=false`, `joinAction`, `joinRoomCode` 설정.
- 입장 성공 시 `joinPending=false`, `joinAccepted=true`.
- 입장 실패 시 `joinError` 설정, 연결 실패 시 `connectionError` 설정.

## 사용 API
- 직접 HTTP 호출 없음.
- 웹소켓 연결 파라미터로 입장 의도 전달:
  - `action` (`0`: 빠른입장/방참여, `1`: 방만들기)
  - `roomCode` (방참여 시)
  - `nickname`

## 성공 흐름
- `session.joinAccepted` 감지 후 게임 페이지로 이동한다.
- 기존 join 파라미터는 세션 매니저에서 정리된다.

## 실패 흐름
- 입장 거절(`1999`) 시 입장 실패 모달(사유+메시지) 표시.
- 연결 실패/세션 끊김 시 연결 실패 모달(사유+메시지) 표시.
- 오류 모달 확인 시 오류 상태만 해제하고 화면은 입장 페이지 유지.

## 로딩 처리
- `joinPending` 동안 버튼 비활성화.
- 빠른입장 버튼 텍스트를 `입장 중...`으로 표시.

## 빈 상태 처리
- 초대코드가 비어 있으면 방참여 모달 참가 버튼 비활성화.
- 닉네임 공백이면 입장 버튼 비활성화.

## 검증(Validation)
- 닉네임: 공백 제거 후 1자 이상 10자 이하.
- 방코드: 공백 제거 후 1자 이상.
- 방코드 입력 시 대문자 정규화.
- joinPending 중 중복 요청 차단.

## 상황별 인터랙션/액션 디테일
- 메인 닉네임 입력 포커스: 입력창 포커스 시 `outline: 2px rgba(225, 122, 46, 0.35)`가 표시되어 현재 입력 위치를 강조한다.
- 메인 액션 버튼 상태: 공통 버튼은 hover 시 `translateY(-1px)`로 떠오르고, 비활성(`disabled`) 시 `opacity: 0.5` + `not-allowed` 커서로 전환된다.
- 빠른입장 진행 중: `session.joinPending=true`면 `빠른 입장` 라벨이 `입장 중...`으로 바뀌고, 빠른입장/방만들기/방참여 버튼이 함께 잠긴다.
- 방참여 모달 열림/닫힘: `joinModalOpen`이 true면 블러 백드롭과 모달 카드가 나타난다. 백드롭 클릭은 닫힘, 모달 내부 클릭은 `stopPropagation`으로 닫힘이 차단된다.
- 방코드 입력 액션: 입력 즉시 대문자 정규화(`toUpperCase`)가 적용되어 소문자 입력이 화면에서 즉시 대문자로 치환된다.
- 방참여 참가 버튼 가드: 모달 내 닉네임/방코드 조건 미충족 또는 `joinPending`이면 버튼이 비활성화되어 클릭 자체가 막힌다.
- 오류 모달 우선순위: `joinError` 발생 시 입장 실패 모달이 최우선으로 표시되고, 이때 일반 방참여 모달은 강제로 닫힌다. `joinError`가 없고 `connectionError`가 있으면 연결 실패 모달이 표시된다.
- 오류 모달 닫기 인터랙션: 오류 모달은 확인 버튼뿐 아니라 백드롭 클릭으로도 닫을 수 있다.
- 초대 링크 자동 진입: 경로/쿼리에서 roomCode를 읽어 첫 렌더 시 방참여 모달을 자동 오픈해 사용자가 곧바로 코드 확인/수정 후 참가할 수 있게 만든다.

## 부수 효과(Side Effect)
- 초대 경로/쿼리 읽기.
- 입장 성공 시 라우팅 전환(`/game`).
- 오류 발생 시 모달 표시.

## 엣지 케이스
- 이미 `joinPending` 또는 `joinAccepted`면 추가 요청 무시.
- 초대 링크로 진입했지만 오류가 발생하면 자동 오픈 모달을 닫아 오류 모달 우선 표시.

## 관련 엔티티
- `session.nickname`, `session.joinPending`, `session.joinAccepted`
- `session.joinError`, `session.connectionError`
- `session.joinAction`, `session.joinRoomCode`

## 현재 마이그레이션 상태
- 신규 src 존재 여부: 존재 (`EntryPage`, `EntryJoinView`, `useEntryJoinForm`).
- behavior parity 충족 여부: 일부 충족.
- 아직 누락된 부분:
  - 세부 UX 문구/레이아웃은 변경됨.
- migration 위험 요소:
  - 입장 실패와 연결 실패의 상태 전이가 라우팅/세션 해제 로직과 엮여 있어 회귀 가능성 존재.
