# 보드/그리기/캔버스

## 사용자 목적
- 출제자는 그림을 그리고, 참가자는 그림과 힌트를 보고 정답을 유추한다.
- 로비에서는 공용 낙서판을 사용한다.

## 진입 위치
- 게임 페이지 중앙 보드 패널.
- 보드 툴바(펜/지우개/채우기/굵기/색상/전체지우기).

## 주요 동작 흐름
1. 사용자가 포인터로 드로잉을 시작하면 draft stroke를 만든다.
2. 이동 중 포인트가 일정 개수(5개)를 넘으면 청크를 잘라 즉시 전송한다.
3. 포인터 종료 시 남은 청크를 전송하고 최종 stroke를 로컬 커밋한다.
4. 채우기 도구는 클릭 시 즉시 단일 stroke 생성 후 전송/커밋한다.
5. 전체지우기는 로컬 캔버스를 즉시 비우고 clear 마커를 전송한다.
6. 러닝 상태에서는 턴 캔버스, 로비 상태에서는 로비 캔버스를 렌더링한다.

## 상태 변화
- 툴바 로컬 상태: `tool`, `size`, `color`.
- 그리기 가능 상태: `canDraw`.
- 캔버스 상태: `lobbyCanvasStrokes` 또는 `currentTurn.canvasStrokes`.
- 비밀 단어 배너/설명 말풍선 열림 상태.

## 사용 API
- 웹소켓 이벤트:
  - `201 DRAW_STROKE` (일반 stroke/clear 마커)
- 로컬 렌더링:
  - `onCommitStroke`로 optimistic 반영
  - inbound stroke는 queue 후 배치 반영(legacy)

## 성공 흐름
- 출제자 턴에는 실시간으로 선이 그려지고 상대 사용자에게 동기화된다.
- 로비 공유 드로잉도 동일 방식으로 동작한다.
- 비밀 단어 배너는 역할(출제자/정답자/추리자)에 따라 표시가 달라진다.

## 실패 흐름
- 그리기 불가 상태에서 입력하면 이벤트를 막고 무시한다.
- 소켓 미연결 시 전송 실패가 발생해도 로컬 커밋은 남을 수 있다.

## 로딩 처리
- 캔버스 자체 로딩 상태는 없음.
- 리사이즈 시 backing store 재설정 후 전체 재렌더링 수행.

## 빈 상태 처리
- stroke가 없으면 빈 보드 배경만 표시.
- 선택 단어/힌트가 없으면 마스킹 기호(`●`)로 대체 표시.

## 검증(Validation)
- 그리기 권한:
  - 로비: 설정 패널 닫힘 상태에서만 그리기 허용.
  - 러닝: 출제자 + `DRAWING` 페이즈에서만 허용.
- 색상 선택 권한:
  - 출제자 턴 외에는 제한(공유 페이즈 강제 색상).
- 크기/툴 선택도 `canDraw`가 false면 비활성.

## 상황별 인터랙션/액션 디테일
- 보드 정답 하이라이트: 내가 정답자가 되는 라운드에는 보드 프레임에 `board-frame-correct-highlight`가 붙어 녹색 테두리(`#2ba95d`)와 이중 외곽 글로우가 표시된다.
- 비밀 단어 배너 열림/닫힘: `secret-word-banner-open/closed` 전환으로 `opacity`와 `translate3d`가 바뀌며, 닫힘 상태는 상단 바깥으로 밀려난다.
- 비밀 단어 배너 등장 모션: `secret-word-banner-landing`에서 `secret-word-banner-drop` 애니메이션(위에서 낙하 + scale 변화)이 한 번 실행된다.
- 비밀 단어 설명 버블 토글: 출제자만 `?` 버튼이 보이고, 클릭 시 설명 버블이 열린다. 바깥 영역 `pointerdown` 이벤트가 들어오면 즉시 닫힌다.
- 설명 버블 스크롤: 긴 설명은 버블 내부에서만 세로 스크롤되고 스크롤바는 숨겨진다.
- 로비 시작 버튼 가시성 전환: 준비 완료면 `board-start-game-button-open`(보임/클릭 가능), 미완료면 `...-closed`(숨김/클릭 차단)로 바뀌며 `translateY` 이동이 동반된다.
- 시작 버튼 hover 강조: hover 시 배경 그라디언트가 밝아지고 border-color, box-shadow가 강화된다.
- 설정 버튼/시작 버튼 모션: 둘 다 `transform`, `opacity`, `border-color`, `box-shadow` 전이가 걸려 상태 전환 때 즉시 ‘밀고 들어오는’ 느낌을 준다.
- 툴바 버튼 상태: 펜/지우개/채우기는 현재 도구일 때 `primary-button`, 아니면 `secondary-button`으로 렌더링되어 선택 상태가 색으로 분리된다.
- 팔레트 활성 컬러 표시: 선택된 색상은 `color-swatch-active`로 외곽 링이 생긴다.
- 공유 드로잉 페이즈 색상 제한: 전체 팔레트 사용 불가 상태에서는 강제 색상을 제외한 스와치가 회색조로 보이고 클릭도 막힌다.
- 캔버스 입력 억제: 드로잉 캔버스는 `touch-action: none`, 텍스트 선택/컨텍스트 메뉴/드래그/제스처를 차단해 선 그리기 동작이 끊기지 않게 유지한다.
- 포인터 스트로크 처리: 드래그 중 5포인트 단위 청크를 전송하고, 손을 떼면 잔여 포인트를 전송한 뒤 최종 stroke를 확정한다.
- `canDraw=false` 시 입력: 포인터 다운에서 즉시 `preventDefault` 후 반환되어 시각 변화 없이 무시된다.

## 부수 효과(Side Effect)
- 터치/제스처/컨텍스트메뉴 기본 동작 차단.
- 텍스트 선택 제거.
- 캔버스 clear 시 inbound 큐도 즉시 비움.

## 엣지 케이스
- `WORD_CHOICE`에서 단어 선택 실패 시 fallback 단어로 진행할 수 있도록 로컬 대체 흐름 존재.
- `selectedWordDescription`은 출제자에게만 `?` 버튼으로 표시.
- 힌트 패턴이 비어 있으면 답 길이 기반 마스킹으로 대체.

## 관련 엔티티
- `room.lobbyCanvasStrokes`
- `room.currentTurn.canvasStrokes`
- `currentTurn.selectedWord`, `hintPattern`, `answerLength`
- `room.settings.hintRevealSec`, `hintLetterCount`

## 현재 마이그레이션 상태
- 신규 src 존재 여부: 존재 (`DrawingCanvas`, `GameBoardPanel`, `useGameBoardControls`).
- behavior parity 충족 여부: 부분 충족.
- 아직 누락된 부분:
  - legacy 비밀 단어 설명 말풍선/도움말 버튼 UX가 신규에 없음.
  - legacy의 공유 페이즈 색상 제한/강제 컬러 표현이 신규에서 단순화됨.
  - legacy inbound stroke 배치 처리(`requestAnimationFrame` 큐) 최적화가 신규에 명시적으로 없음.
- migration 위험 요소:
  - 장시간 드로잉/모바일 환경에서 성능 체감 및 단어 배너 UX 불일치 위험.
