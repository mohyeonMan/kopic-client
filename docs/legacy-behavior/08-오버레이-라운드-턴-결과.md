# 오버레이/라운드/턴/결과 흐름

## 사용자 목적
- 게임 단계 전환(게임 시작, 라운드 시작, 턴 시작, 단어 선택, 턴 종료, 결과)을 명확히 인지한다.
- 현재 단계에서 필요한 행동(단어 선택, 정답 확인)을 즉시 수행한다.

## 진입 위치
- 게임 보드 위 `TurnOverlay` 계층.
- `useGameStageOverlay`가 계산한 `activeStageOverlay`, `previewMode`를 기반으로 표시.

## 주요 동작 흐름
1. 게임 시작/라운드 시작/턴 시작에서 자동 프리뷰 오버레이를 노출한다.
2. 자동 프리뷰는 5초 후 `actual` 모드로 복귀한다.
3. 단어 선택 단계에서는 출제자에게 선택 버튼을, 나머지 사용자에게 대기 문구를 표시한다.
4. 턴 종료 단계에서는 정답, 획득 점수, 역할별 결과 테이블을 노출한다.
5. 결과 단계에서는 우승자(동점 포함)와 순위 목록을 표시하고 로비 복귀 카운트다운을 보여준다.

## 상태 변화
- `overlayPreview`: `gameStart`/`roundStart`/`turnStart`/`actual` 등.
- `activeStageOverlay`, `pendingStageOverlay`, `stageOverlayOpen`.
- `turnEndOverlaySnapshot`: 턴 종료 시점 정답/점수 스냅샷 고정.

## 사용 API
- 직접 네트워크 호출은 없고, 상위에서 전달된 턴/라운드 상태를 사용.
- 단어 선택 버튼 클릭 시 상위 콜백을 통해 `WORD_CHOICE(203)` 요청.

## 성공 흐름
- 사용자에게 단계 전환 의도가 명확히 전달된다.
- 턴 종료 후 정답과 점수 증감 이유를 바로 확인할 수 있다.

## 실패 흐름
- 현재 턴 정보가 불완전하면 일부 오버레이는 숨김 처리된다.
- 카운트다운 값이 누락되면 정적 문구로 대체 표시한다.

## 로딩 처리
- 별도 로딩 스피너 없음.
- 단계 전환은 애니메이션 열림/닫힘 상태로 표현.

## 빈 상태 처리
- 단어 선택지 배열이 비어 있으면 선택 버튼 영역을 숨김.
- 순위가 비어 있으면 결과 제목을 일반 종료 문구로 처리.

## 검증(Validation)
- 자동 프리뷰 키(`gameId`, `roundNo`, `turnId`)를 기준으로 중복 표시 방지.
- transition 종료 이벤트의 대상/속성(`transform`) 검증 후 다음 오버레이 전환.
- `turnStart` 프리뷰 중 실제 턴이 이미 진행되면 즉시 프리뷰 해제.

## 상황별 인터랙션/액션 디테일
- 오버레이 개폐 기본 규칙: `stageOverlayOpen`과 `activeStageOverlay` 조합으로 `...-open/closed` 클래스가 바뀌며, 대부분 `transform + opacity` 전환으로 화면을 덮고 걷어낸다.
- 단어 선택 카드 슬라이드: `canvas-overlay-card-word-choice-open`은 상단에 고정되어 보이고, `...-closed`는 `translate(-50%, calc(-100% - 24px))`로 화면 위로 퇴장한다.
- 전체 오버레이 슬라이드: `canvas-full-overlay-open`은 `translateY(0)`, `...-closed`는 `translateY(-100%)`로 상단 밖으로 밀려난다.
- 전환 완료 판정: `onTransitionEnd`는 `event.target === currentTarget`이면서 `propertyName === 'transform'`일 때만 다음 단계 전환을 허용한다.
- 단어 선택 버튼 인터랙션: hover 시 `translateY(-2px)`와 그림자 강화가 들어가고, 선택지 개수(3/4/5)에 따라 버튼 배치 폭이 동적으로 바뀐다.
- 턴 종료 점수행 강조: 점수행 hover 시 살짝 떠오르며(`translateY(-1px)`), 정답자 행은 녹색 계열 배경/테두리, 출제자 행은 주황 계열 배경/테두리로 분리된다.
- 결과 화면 진입 모션: 결과 스크린은 `result-screen-shutter-rise`로 아래에서 위로 올라오며 등장한다.
- 결과 테두리 점멸: 결과 스크린 외곽은 `result-screen-border-flash`로 빨강/노랑 테두리와 글로우가 번갈아 깜빡여 종료 타이밍을 강하게 알린다.
- 순위 1등 강조: `result-ranking-item-winner`에 금색 계열 border/background가 적용되어 동점 우승 상황에서도 상단 우승자 그룹을 시각적으로 구분한다.
- 결과/턴종료 스크롤: 점수표 본문(`earned-score-table-body`)과 순위 목록(`result-ranking-list`)은 독립 스크롤을 가지며 별도 스크롤바 스타일이 적용된다.
- 카운트다운 칩 배치: 단어선택/턴종료/결과 단계에서 초 단위 카운트다운이 우상단 또는 헤더 우측 칩으로 배치되어 남은 시간을 지속 노출한다.

## 부수 효과(Side Effect)
- 다수 timeout과 `requestAnimationFrame`으로 오버레이 개폐 타이밍 제어.
- 컴포넌트 언마운트 시 timeout/raf 정리.

## 엣지 케이스
- 오버레이 전환 중 다른 단계 이벤트가 들어오면 `pendingStageOverlay`로 큐잉 후 순차 전환.
- 턴 종료 오버레이는 스냅샷을 유지해 중간 상태 변화에도 동일 결과를 보여준다.

## 관련 엔티티
- `room.roomState`, `currentRound`, `currentTurn`
- `currentTurn.deadlineAtMs`, `remainingSec`
- `earnedPoints`, `correctSessionIds`, `selectedWord`

## 현재 마이그레이션 상태
- 신규 src 존재 여부: 존재 (`GameStageOverlay`, `useGameStageOverlay`).
- behavior parity 충족 여부: 부분 충족.
- 아직 누락된 부분:
  - legacy의 5초 자동 프리뷰 상태머신/큐잉 전환이 신규에서 단순 계산으로 축소됨.
  - gameStart/roundStart/result의 세부 카운트다운 표시가 신규에 축소됨.
  - 턴 종료 점수 테이블 표현이 단순화됨.
- migration 위험 요소:
  - 단계 전환 타이밍 체감이 달라져 사용자 행동 타이밍(특히 단어 선택/정답 확인)이 흔들릴 위험.
