# 로비 설정/게임 시작

## 사용자 목적
- 방장이 게임 규칙을 조정하고, 시작 가능한 조건에서 게임을 시작한다.
- 참가자는 현재 설정을 확인한다.

## 진입 위치
- 게임 페이지 로비 상태(`roomState=LOBBY`)의 중앙 보드 영역.
- `설정 열기/설정 보기` 버튼으로 오버레이 진입.

## 주요 동작 흐름
1. 로비에서 설정 버튼을 열면 설정 오버레이를 표시한다.
2. 방장은 라운드 수, 그리기 시간, 단어 선택 시간, 선택 단어 수, 힌트 주기/글자 수를 변경한다.
3. 비공개 방에서는 커스텀 단어 모드와 커스텀 단어 원문까지 수정할 수 있다.
4. 설정 변경은 낙관적으로 로컬 반영 후 서버에 설정 업데이트 이벤트를 전송한다.
5. 시작 조건(최소 인원, 커스텀 단어 모드 조건)을 만족하면 게임 시작 버튼이 활성화된다.

## 상태 변화
- `settingsOpen` 토글.
- `room.settings` 부분 갱신.
- 시작 버튼 활성/비활성 상태 변화.
- 로비 종료(`roomState != LOBBY`) 시 설정 오버레이 자동 닫힘.

## 사용 API
- 웹소켓 클라이언트 이벤트:
  - `107 GAME_SETTINGS_UPDATE_REQUEST`
  - `200 GAME_START_REQUEST`
- compact settings 인코딩 배열 전송.

## 성공 흐름
- 설정 변경 즉시 화면에 반영.
- 서버에서도 `107/308` 수신 시 설정 정규화 후 반영.
- 시작 요청 성공 시 `RUNNING` 상태로 전환되고 라운드/턴 흐름 시작.

## 실패 흐름
- 방장이 아닌 사용자의 설정 변경 요청은 로컬 단계에서 무시.
- 시작 조건 미충족 시 버튼 비활성화로 요청 자체를 차단.

## 로딩 처리
- 별도 로딩 스피너 없음.
- 설정은 즉시 반영 후 서버 동기화 결과를 후속 반영한다.

## 빈 상태 처리
- 비공개 방이 아니면 커스텀 단어 입력 필드를 숨긴다.

## 검증(Validation)
- 방장 권한 검증: `hostSessionId === sessionId`일 때만 변경 허용.
- 시작 조건 검증:
  - 참가자 2명 이상.
  - `CUSTOM_ONLY` 모드에서는 `customWordsRaw` 1자 이상.
- 수치 옵션은 사전 정의된 선택지로 제한.

## 상황별 인터랙션/액션 디테일
- 설정 카드 열림/닫힘: `settingsOpen`에 따라 `canvas-overlay-card-settings-open/closed` 클래스가 전환되며 `opacity`와 `transform`(위치/스케일) 애니메이션으로 슬라이드된다.
- 뷰포트 높이 대응: 컨테이너 높이가 낮으면 설정 카드 기준점이 중앙에서 상단으로 바뀌고, 닫힘 시 `translate(-50%, calc(-100% - 18px))`로 화면 밖으로 밀린다.
- 설정 카드 스크롤: 카드 자체가 `overflow: auto` + `overscroll-behavior: contain`이라 옵션이 많아도 배경 페이지 스크롤로 전이되지 않는다.
- 방장/비방장 조작 차이: 비방장은 `select`, `textarea`가 `disabled`이고 `select-no-caret` 클래스가 붙어 드롭다운 캐럿까지 숨겨진 읽기 전용 상태처럼 보인다.
- 검증 문구 강조: `CUSTOM_ONLY`인데 단어 원문이 비면 `settings-validation-text`가 노출되어 시작 불가 사유를 즉시 보여준다.
- 로비 우상단 액션 버튼: `설정 열기/설정 닫기/설정 보기` 텍스트가 상태와 권한에 따라 즉시 바뀐다.
- 시작 버튼 가시 상태: 비공개 방 방장일 때만 버튼 DOM이 존재하며, 준비 완료 시 `board-start-game-button-open`, 미충족 시 `...-closed`로 전환되어 `opacity/visibility/translateY`가 함께 바뀐다.
- 시작 버튼 시각 피드백: hover 시 배경 그라디언트가 밝아지고 border/box-shadow가 강화된다.
- 닫기 버튼 강조: 설정 패널의 `닫기` 버튼은 hover 시 배경이 더 밝아지고 텍스트 명도가 올라간다.

## 부수 효과(Side Effect)
- 설정 변경 시 서버 전송.
- 시작 요청 시 서버 전송.
- 로비 종료 시 설정 모달 자동 닫기.

## 엣지 케이스
- 설정 패치 직후 화면 이탈 시에도 로컬 반영 상태가 남아있다가 스냅샷으로 재동기화될 수 있다.
- 커스텀 단어 모드와 원문 조합이 맞지 않으면 시작 버튼 비활성 + 검증 문구 노출.

## 관련 엔티티
- `room.settings`
- `room.hostSessionId`
- `room.roomType`
- `session.sessionId`

## 현재 마이그레이션 상태
- 신규 src 존재 여부: 존재 (`RoomLobbyView`, `useRoomLobbyControls`).
- behavior parity 충족 여부: 부분 충족.
- 아직 누락된 부분:
  - legacy에서 제공하던 전체 설정 항목 중 일부가 신규 UI에서 조작 불가.
  - `CUSTOM_ONLY + customWordsRaw` 시작 제한 검증이 신규 UI에서 동일 수준으로 노출되지 않음.
  - private room 시작 버튼 조건(참가자 수/커스텀 조건) 세부 동작 차이 가능성.
- migration 위험 요소:
  - 서버는 지원하지만 UI에서 설정 조작이 누락되어 기능 축소가 조용히 발생할 수 있음.
