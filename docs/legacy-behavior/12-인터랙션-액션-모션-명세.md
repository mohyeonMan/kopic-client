# 슬라이드/카드 인터랙션 액션 명세

## 사용자 목적
- 사용자가 단계 전환, 패널 전환, 보조 메뉴 표시 상태를 즉시 체감한다.
- 중요한 액션(단어 선택, 설정, 시작 버튼, 채팅 입력)의 문맥 전환을 시각적으로 이해한다.

## 진입 위치
- 게임 페이지 모바일 패널 스위처.
- 보드 오버레이(단어선택/턴시작/턴종료/결과), 로비 설정 카드.
- 참여자 카드, 참여자 말풍선.
- 상단 공유 메뉴, 채팅 도크.

## 주요 동작 흐름
1. 모바일 패널 전환 버튼 클릭 시 `chat`/`participants` 패널이 교대 노출된다.
2. 채팅 입력 포커스 시 강제로 채팅 패널을 활성화하고 스크롤 앵커를 재정렬한다.
3. 단어선택 카드와 설정 카드는 `open/closed` 클래스에 따라 슬라이드 인/아웃된다.
4. 전체 오버레이(`gameStart`, `roundStart`, `turnStart`, `turnEnd`)는 위에서 내려오고 다시 위로 닫힌다.
5. 비밀단어 배너는 드롭 애니메이션 후 고정되고, 조건 변화 시 위로 숨겨진다.
6. private 방 시작 버튼은 토글 상태에 따라 위로 슬라이드 아웃되거나 나타난다.
7. 참여자 카드는 입장 시 좌측에서 슬라이드 인, 퇴장 시 슬라이드 아웃된다.
8. 참여자 말풍선은 짧은 등장/퇴장 모션으로 최근 발화를 표시한다.
9. 공유 메뉴는 버튼 아래에서 슬라이드 다운되고 바깥 클릭/ESC로 닫힌다.
10. 모바일 비활성 채팅 패널은 본문을 숨기고 입력 도크만 고정 하단으로 남긴다.

## 상태 변화
- `mobilePanel`, `isChatComposerFocused`.
- `overlayPreview`, `activeStageOverlay`, `stageOverlayOpen`.
- `settingsOpen`.
- `openedDescriptionKey`.
- `shareMenuOpen`, `qrModalOpen`.
- 참여자 카드 phase(`enter`, `stable`, `exit`).

## 사용 API
- 네트워크 API 없음.
- 브라우저 이벤트:
  - `pointerdown`, `keydown(Escape)`, `focus`, `blur`, `scroll`, `resize`.
- 내부 상태 머신:
  - 오버레이 전환 시 `requestAnimationFrame`, `setTimeout` 사용.

## 성공 흐름
- 사용자는 현재 단계 전환을 모션으로 즉시 인지한다.
- 모바일에서 입력 시 패널/스크롤 문맥이 자동 정렬되어 오입력 가능성이 줄어든다.
- 설정/단어선택/공유 메뉴가 일관된 열림-닫힘 패턴으로 동작한다.

## 실패 흐름
- 트랜지션 이벤트가 예상대로 오지 않으면 오버레이 큐 전환이 지연될 수 있다.
- ref 대상이 없으면 포커스 이동/스크롤 정렬 일부가 생략된다.

## 로딩 처리
- 로딩 스피너 대신 모션 상태(`open/closed`)로 전환 진행을 표현한다.

## 빈 상태 처리
- 단어선택지가 비어 있으면 카드 본문 버튼 영역을 숨긴다.
- 참여자/채팅 데이터가 없으면 해당 모션 대상 자체가 생성되지 않는다.

## 검증(Validation)
- 오버레이 전환은 `transitionend`의 `target`, `propertyName(transform)`를 검사한다.
- 모바일 패널 클래스는 상태값으로 단일 출처(`activeMobilePanel`)에서 결정한다.
- 채팅 도크는 비활성 모드에서도 입력만 남기도록 영역 분리 규칙을 적용한다.

## 부수 효과(Side Effect)
- 다중 `requestAnimationFrame`으로 패널 포커스 시점 정렬.
- 전역 입력/포인터 이벤트 리스너 등록/해제.
- body 스크롤 잠금(QR 모달 오픈 시).

## 엣지 케이스
- 채팅 입력 포커스 중에는 사용자가 참여자 탭을 눌러도 채팅 패널이 우선 유지된다.
- 오버레이 전환 도중 새 단계가 도착하면 pending 큐로 저장 후 순차 반영한다.
- 모바일 비활성 채팅 패널은 높이 0이지만 입력 도크는 고정 유지된다.

## 관련 엔티티
- 페이지 상태: `mobilePanel`, `isChatComposerFocused`.
- 오버레이 상태: `overlayPreview`, `activeStageOverlay`, `pendingStageOverlay`, `stageOverlayOpen`.
- UI 상태: `settingsOpen`, `shareMenuOpen`, `participant phase`.

## 현재 마이그레이션 상태
- 신규 src 존재 여부: 부분 존재.
- behavior parity 충족 여부: 미충족 항목 다수.
- 아직 누락된 부분:
  - 참여자 카드 입퇴장 슬라이드, 참여자 말풍선 모션.
  - 오버레이 카드의 레거시 상태머신 기반 슬라이드 큐 전환.
  - 모바일 비활성 채팅 패널의 고정 입력 도크 패턴.
  - 비밀단어 배너 드롭/닫힘 모션 및 설명 버블 토글 UX.
- migration 위험 요소:
  - 기능은 살아 있어도 상호작용 감각이 약화되어 “동작이 느리거나 불명확하다”는 회귀 체감이 발생할 수 있음.
